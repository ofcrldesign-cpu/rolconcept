24. CANONICAL

Definir uma URL canonical única para a página.

Exemplo:

<link
  rel="canonical"
  href="https://www.seudominio.com.br/"
>
Regras
Utilizar URL absoluta.
Usar HTTPS.
Evitar múltiplas URLs para o mesmo conteúdo.
Definir a versão preferencial com ou sem www.
Redirecionar versões duplicadas para a URL canonical.
25. META ROBOTS

<meta
  name="robots"
  content="index, follow"
>

28. PERFORMANCE

A página deve priorizar Core Web Vitals e carregamento rápido.

Imagens
Utilizar WebP ou AVIF.
Comprimir imagens.
Definir width e height.
Utilizar loading="lazy" em imagens fora da primeira dobra.
Utilizar fetchpriority="high" na imagem principal quando apropriado.
Evitar imagens maiores que o necessário.
CSS
Minimizar CSS.
Remover estilos não utilizados.
Evitar dependências desnecessárias.
Priorizar CSS crítico.
JavaScript
Utilizar JavaScript apenas quando necessário.
Evitar bibliotecas pesadas sem necessidade.
Carregar scripts não críticos com defer.
Evitar bloquear o carregamento inicial.

O site não deve funcionar apenas como uma página informativa.

A experiência deve conduzir o visitante por três etapas:

IDENTIFICAÇÃO → CONFIANÇA → AGENDAMENTO

O usuário deve primeiro se identificar com o conceito do ROL CONCEPT, depois encontrar provas de qualidade e diferenciais e, finalmente, ter um caminho extremamente simples para entrar em contato e agendar seu atendimento.

Para a identidade visual, a paleta e a tipografia devem ser tratadas separadamente do arquivo da logo. 


1. Paleta de Cores — ROL CONCEPT

A identidade visual trabalha uma paleta monocromática sofisticada, coerente com o logotipo e adequada para um site de salão contemporâneo.

Cor	HEX	RGB	CMYK
Preto	#000000	0, 0, 0	0, 0, 0, 100
Grafite	#1A1A1A	26, 26, 26	0, 0, 0, 90
Cinza Médio	#666666	102, 102, 102	0, 0, 0, 60

Off-White	#F8F8F8	248, 248, 248	0, 0, 0, 3
Branco	#FFFFFF	255, 255, 255	0, 0, 0, 0
Aplicação recomendada no site
PRETO       → #000000 → fundos, header, seções premium
GRAFITE     → #1A1A1A → fundos secundários, cards
CINZA MÉDIO → #666666 → textos secundários
CINZA CLARO → #D9D9D9 → bordas e divisores
OFF-WHITE   → #F8F8F8 → fundos claros
BRANCO      → #FFFFFF → textos sobre fundo escuro e logo

Direção visual: preto + branco como base, grafite para profundidade e cinzas para hierarquia.

2. Tipografia — ROL CONCEPT
Tipografia identificada/mais próxima da logo

A logo possui características de uma sans-serif geométrica/neogrotesca, com:

Letras minúsculas.
Traços uniformes.
Construção limpa.
Aparência contemporânea.
Baixo contraste.
Formas arredondadas.
Visual minimalista e sofisticado.

Uma aproximação adequada para o lettering é:

Helvetica Neue

Uso: identidade da marca / títulos institucionais.

Combinação recomendada para o site

Títulos: Helvetica Neue Bold / Semibold
Subtítulos: Helvetica Neue Medium
Textos: Helvetica Neue Regular
